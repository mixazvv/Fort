# Fort: режим BODYCAM для Fortnite (UEFN)

Режимы в стиле игры *Bodycam*: вид от первого лица «с нагрудной камеры», мигающий REC и таймкод, никакого игрового HUD, смерть с одного-двух попаданий, ночь, шум и звук рации.

| Режим | Суть |
|---|---|
| **Раунды** | 5 на 5, одна жизнь за раунд, до 5 побед |
| **Deathmatch** | каждый сам за себя, возрождение, до 25 убийств или 10 минут |
| **Гонка вооружений** | каждое убийство меняет оружие на следующее, побеждает тот, кто пройдёт всю лестницу |

Карта для всех трёх режимов: **«Склад 17»** ([docs/MAP.md](docs/MAP.md)).

## Что в репозитории

| Путь | Содержимое |
|---|---|
| `verse/bodycam_rounds_manager.verse` | Режим «Раунды»: одна жизнь, таймер, счёт между раундами, выдача оружия |
| `verse/bodycam_deathmatch_manager.verse` | Режим Deathmatch |
| `verse/bodycam_gungame_manager.verse` | Режим «Гонка вооружений» |
| `verse/bodycam_respawn_mode.verse` | Общая основа режимов с возрождением: спавны, таймер матча, лидер, конец матча |
| `verse/bodycam_agent.verse` | Реакции игрока: попадания, ранение, выбывание, одышка после бега |
| `verse/bodycam_overlay.verse` | Оверлей камеры: REC, таймкод, позывной, рация, вспышки, «НЕТ СИГНАЛА» |
| `verse/bodycam_common.verse` | Общий интерфейс режимов, цвета, форматирование времени |
| `docs/GDD.md` | Дизайн: правила режимов, атмосфера, оружие |
| `docs/MAP.md` | Карта «Склад 17»: зоны, маршруты, координаты спавнов и света, порядок сборки |
| `docs/SETUP.md` | Пошаговая сборка в UEFN: Island Settings, устройства, пост-обработка, свет, чек-лист |

## Быстрый старт

1. Создайте пустой проект в UEFN.
2. Скопируйте `verse/*.verse` в Verse-папку проекта и соберите (Ctrl+Shift+B).
3. Соберите карту по [docs/MAP.md](docs/MAP.md).
4. Поставьте менеджер нужного режима и устройства из [docs/SETUP.md](docs/SETUP.md).
5. Настройте Post Process Volume по таблице.

## Статус

Код не проверялся компилятором UEFN: из облачного окружения его не запустить. Возможны мелкие расхождения с текущей версией API, известные места перечислены в `docs/SETUP.md`, раздел 8.
