# Fort: режим BODYCAM для Fortnite (UEFN)

Тактический командный режим 5 на 5 в стиле игры *Bodycam*: вид от первого лица «с нагрудной камеры», мигающий REC и таймкод, никакого игрового HUD, смерть с одного-двух попаданий, ночь, шум и звук рации.

## Что в репозитории

| Путь | Содержимое |
|---|---|
| `verse/bodycam_game_manager.verse` | Менеджер матча: раунды, одна жизнь, таймер, счёт, выдача оружия, звуки |
| `verse/bodycam_agent.verse` | Реакции игрока: попадания, ранение, выбывание, одышка после бега |
| `verse/bodycam_overlay.verse` | Оверлей камеры: REC, таймкод, позывной, рация, вспышки, «НЕТ СИГНАЛА» |
| `verse/bodycam_common.verse` | Цвета и форматирование времени |
| `docs/GDD.md` | Дизайн режима: правила, атмосфера, карта, оружие |
| `docs/SETUP.md` | Пошаговая сборка в UEFN: Island Settings, устройства, пост-обработка, свет, чек-лист |

## Быстрый старт

1. Создайте пустой проект в UEFN.
2. Скопируйте `verse/*.verse` в Verse-папку проекта и соберите (Ctrl+Shift+B).
3. Поставьте на уровень `bodycam_game_manager` и устройства из [docs/SETUP.md](docs/SETUP.md).
4. Настройте Post Process Volume по таблице, сделайте карту тёмной.

## Статус

Код не проверялся компилятором UEFN: из облачного окружения его не запустить. Возможны мелкие расхождения с текущей версией API, известные места перечислены в `docs/SETUP.md`, раздел 7.
