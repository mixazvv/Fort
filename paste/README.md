# Готовые блоки для вставки в UEFN (Ctrl+V)

Unreal Editor умеет вставлять объекты и узлы из текста. Порядок для любого файла:

1. Откройте `.txt` в Блокноте.
2. **Ctrl+A**, затем **Ctrl+C**.
3. В UEFN кликните в нужное место и нажмите **Ctrl+V**.

Файлы собираются скриптом `tools/generate_paste.py`. Если UEFN что-то не примет, пришлите скриншот или текст ошибки из «Журнала выходных данных», и файл перегенерируется.

## 01_postprocess.txt — картинка «нагрудной камеры»

Объём постобработки со всеми настройками сразу: цвет без синевы, зерно, виньетка, аберрация, блум, медленная экспозиция, смаз.

1. Удалите старый Post Process Volume, если ставили его вручную.
2. Кликните в окно с картой и нажмите Ctrl+V.
3. В «Структуре» появится папка **Bodycam** с объектом **Bodycam_PostProcess**.
4. Нажмите «Обновить сеанс».

## 02_fisheye_nodes.txt — «рыбий глаз»

Здесь вставляются только узлы, сам материал создаётся вручную (около минуты):

1. В панели ресурсов: правый клик → **Материал**, назовите `M_Fisheye`, откройте двойным кликом.
2. Слева в «Сведениях» поставьте **Material Domain = Post Process**.
3. Кликните по пустому месту графа и нажмите Ctrl+V. Появится цепочка из 9 узлов.
4. Протяните линию от выхода **Color** последнего узла (*SceneTexture*) ко входу **Emissive Color** большого узла материала.
5. Сохраните (Ctrl+S).
6. Выделите **Bodycam_PostProcess**, в «Сведениях» найдите поиском `Post Process Materials`, нажмите **+**, выберите **Asset Reference** и затем **M_Fisheye**.

Сила изгиба задаётся числом `0.25` в узле *Multiply* после *DotProduct*: больше — сильнее «рыбий глаз». Число `0.88` в следующем *Multiply* приближает картинку, чтобы по краям не было пустоты.

## 03_warehouse17.txt — коробка карты «Склад 17»

88 объектов по плану из `docs/MAP.md`:
- стены с проёмами дверей;
- полы и крыши;
- Г-образная антресоль с перилами и двумя пандусами;
- стеллажи, фура, контейнеры, котёл;
- 9 ламп (3 из них в папке *Flicker*, их позже заставим мерцать).

1. Кликните в окно с картой и нажмите Ctrl+V.
2. В «Структуре» появится папка **Warehouse17** с подпапками (стены, полы, крыши и т.д.). Угол карты стоит в точке (0, 0, 0).
3. Чтобы сдвинуть всю карту: выделите папку Warehouse17 и перетащите стрелками.

Все блоки сделаны из стандартного куба движка `/Engine/BasicShapes/Cube`. Если после вставки ничего не видно или в журнале есть ошибка про `Cube`:
1. Найдите в панели ресурсов любой простой куб.
2. Правый клик → **Копировать ссылку** (Copy Reference).
3. Пришлите эту строку, и я перегенерирую файл под ваш путь.

Если пандус наклонён не в ту сторону, выделите его и поменяйте знак угла **Крен** (Roll) в «Сведениях».

Спавны и текстуры пока ставятся вручную: координаты спавнов есть в `docs/MAP.md`, материалы описаны в `docs/TEXTURES.md`.
